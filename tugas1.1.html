Situs Web

Untuk web page, lihat Laman web.

Untuk kegunaan lain, lihat Situs.

Situs web (bahasa Inggris: website) adalah sekumpulan halaman web yang saling berhubungan yang umumnya berada pada peladen yang sama dan berisikan kumpulan informasi yang disediakan secara perorangan, kelompok, atau organisasi.

Sebuah situs web biasanya ditempatkan setidaknya pada sebuah server web yang dapat diakses melalui jaringan seperti Internet, ataupun jaringan area lokal (LAN) melalui alamat Internet yang dikenali sebagai URL.

Gabungan atas semua situs yang dapat diakses publik di Internet disebut pula sebagai World Wide Web atau lebih dikenal dengan singkatan WWW.

Meskipun setidaknya halaman beranda situs Internet umumnya dapat diakses publik secara bebas, pada praktiknya tidak semua situs memberikan kebebasan bagi publik untuk mengaksesnya. Beberapa situs web mewajibkan pengunjung untuk melakukan pendaftaran sebagai anggota, atau bahkan meminta pembayaran untuk dapat menjadi anggota dan mengakses isi yang terdapat dalam situs web tersebut. Contohnya situs-situs yang menampilkan pornografi, situs-situs berita, layanan surel (e-mail), dan lain-lain. Pembatasan-pembatasan ini umumnya dilakukan karena alasan keamanan, menghormati privasi, atau karena tujuan komersial tertentu.

Sebuah halaman web adalah berkas yang ditulis sebagai berkas teks biasa (plain text) yang diatur dan dikombinasikan sedemikian rupa dengan instruksi-instruksi berbasis HTML atau XHTML, kadang-kadang pula disisipi dengan sekelumit bahasa skrip.

Berkas tersebut kemudian diterjemahkan oleh peramban web dan ditampilkan seperti layaknya sebuah halaman pada monitor komputer.

Halaman-halaman web tersebut diakses oleh pengguna melalui protokol komunikasi jaringan yang disebut HTTP. Sebagai tambahan untuk meningkatkan aspek keamanan dan privasi, situs web dapat pula mengimplementasikan mekanisme pengaksesan melalui protokol HTTPS.

Sejarah

Penemu situs web adalah Sir Timothy John “Tim” Berners-Lee, sedangkan situs web yang tersambung dengan jaringan pertama kali muncul pada tahun 1991.

Maksud Tim ketika merancang situs web adalah untuk memudahkan tukar-menukar dan memperbarui informasi pada sesama peneliti di tempat ia bekerja.

Pada tanggal 30 April 1993, CERN, tempat Tim bekerja, mengumumkan bahwa WWW dapat digunakan secara gratis oleh publik.

Sebuah situs web bisa berupa hasil kerja dari perorangan atau individu, atau menunjukkan kepemilikan dari suatu organisasi maupun perusahaan.

Biasanya pembahasan dalam sebuah situs web merujuk pada satu ataupun beberapa topik khusus atau kepentingan tertentu.

Sebuah situs web bisa berisi pranala yang menghubungkan ke situs web lain, demikian pula sebaliknya. Hal ini terkadang membuat perbedaan antara situs web yang dibuat oleh individu atau perseorangan dengan situs web yang dibuat oleh organisasi bisnis menjadi tidak begitu jelas.

Situs web biasanya ditempatkan pada server web. Sebuah server web umumnya telah dilengkapi dengan perangkat-perangkat lunak khusus untuk menangani pengaturan nama ranah serta menangani layanan atas protokol HTTP. Perangkat lunak ini disebut Server HTTP, contohnya Apache HTTP Server atau Internet Information Services (IIS).

Deskripsi

Supaya bisa berkomunikasi dengan semua komputer yang tersambung ke Internet, digunakan protokol komunikasi yang menggunakan TCP/IP (Transmission Control Protocol/Internet Protocol).

Setiap komputer yang terhubung ke Internet mempunyai sebuah alamat, misalnya 192.168.14.96.

Untuk memperoleh informasi atau data di Internet, kita dapat mengaksesnya dengan mengetikkan suatu alamat web pada address bar. Alamat suatu situs di Internet disebut nama domain.

Nama domain adalah alamat permanen situs di dunia Internet yang digunakan untuk mengidentifikasikan sebuah situs. Dengan kata lain, Domain Name adalah alamat yang digunakan untuk menemukan suatu situs pada Internet.

Kaitannya dengan protokol komunikasi TCP/IP, nama domain dapat diibaratkan seperti buku telepon: kita menggunakan sebuah nomor untuk memanggil seseorang.

Contohnya, ketika kita mengakses situs www.wikipedia.com, penjelajah web akan menghubungi alamat IP yang sesuai. Alamat IP yang digunakan suatu situs dapat berubah, sehingga contoh alamat IP tidak selalu berlaku setiap saat.

Istilah umum untuk alamat sumber daya di Internet adalah URL (Uniform Resource Locator), yaitu sarana untuk menentukan alamat yang akan dipakai untuk mengakses Internet.

Alamat URL merupakan alamat khusus untuk file tertentu yang bisa diakses melalui Internet. URL mencakup berbagai jenis file yang bisa diakses melalui Internet, misalnya file HTML, ZIP, RAR, JPG, GIF, dan PNG.

Alamat URL yang lengkap secara umum dapat ditulis sebagai berikut:

Protokol://nama-host/path/nama-file

Protokol menunjukkan jenis protokol yang akan digunakan, yaitu HTTP, FTP, dan sebagainya.

Nama host adalah nama host atau domain yang dipanggil.

Path adalah lokasi atau direktori tempat file-file diletakkan pada web server.

Nama file adalah nama file yang dipanggil.

Contoh URL: http://www.wikipedia.co.id/artikel/ensiklopedia.htm.

Pada contoh URL tersebut:

URL menggunakan protokol HTTP.

Nama domain adalah www.wikipedia.co.id.

Path atau direktori yang dituju adalah artikel.

Nama file yang diakses adalah ensiklopedia.htm.

Jenis Situs Web

Secara garis besar, situs web bisa digolongkan menjadi tiga bagian, yaitu:

1. Situs web statis

2. Situs web dinamis

3. Situs web interaktif

Situs Web Statis

Situs web statis merupakan situs web yang memiliki isi yang tidak dimaksudkan untuk diperbarui secara berkala, sehingga pengaturan ataupun pemutakhiran isi situs dilakukan secara manual.

Ada tiga jenis perangkat utilitas yang biasa digunakan dalam pengaturan situs web statis:

1. Penyunting teks merupakan perangkat utilitas yang digunakan untuk menyunting berkas halaman web, misalnya Notepad atau TextEdit.

2. Penyunting WYSIWYG merupakan perangkat lunak utilitas penyunting halaman web yang dilengkapi antarmuka grafis dalam perancangan serta pendesainannya. Berkas halaman web umumnya tidak disunting secara langsung oleh pengguna; utilitas ini akan membuatnya secara otomatis berdasarkan laman kerja yang dibuat pengguna. Contoh perangkat lunak ini adalah Microsoft FrontPage dan Macromedia Dreamweaver.

3. Penyunting berbasis templat merupakan utilitas tertentu, seperti RapidWeaver dan iWeb. Pengguna dapat membuat situs web tanpa harus mengetahui bahasa HTML, melainkan menyunting halaman seperti halaman biasa. Pengguna dapat memilih templat yang akan digunakan, kemudian utilitas tersebut membuat berkas halaman web secara otomatis.

Situs Web Dinamis

Situs web dinamis merupakan situs web yang secara khusus dirancang agar isi yang terdapat di dalamnya dapat diperbarui secara berkala dengan mudah.

Sesuai dengan namanya, isi situs web ini umumnya akan berubah setelah melewati suatu periode tertentu atau berdasarkan permintaan pengguna. Situs berita adalah salah satu contoh jenis situs yang umumnya menerapkan situs web dinamis.

Berbeda dengan situs web statis, penerapan situs web dinamis umumnya membutuhkan infrastruktur yang lebih kompleks. Hal ini disebabkan karena halaman web umumnya baru dibuat saat ada pengguna yang mengaksesnya. Berbeda dengan situs statis yang umumnya telah membentuk sejumlah berkas halaman saat diunggah di server web, server situs dinamis dapat perlu membuat halaman terlebih dahulu ketika diminta pengguna.

Untuk memungkinkan server web menciptakan halaman saat pengguna mengaksesnya, server umumnya dilengkapi mesin penerjemah bahasa skrip, seperti PHP, ASP, ColdFusion, atau bahasa lainnya, serta perangkat lunak sistem manajemen basis data relasional seperti MySQL.

Struktur berkas situs web dinamis umumnya berbeda dengan situs web statis. Berkas situs statis umumnya merupakan sekumpulan berkas yang membentuk situs web. Sementara itu, berkas situs dinamis umumnya membentuk perangkat lunak aplikasi web yang dijalankan oleh mesin penerjemah server dan berfungsi mengelola pembuatan halaman web saat halaman tersebut diminta pengguna.

Domain

Domain adalah alamat sebuah situs web. Sebenarnya, alamat situs-situs yang ada di Internet pada tingkat jaringan menggunakan angka-angka, misalnya alamat IP. Penggunaan kata-kata sebagai nama domain bertujuan agar alamat lebih mudah diingat daripada harus menghafal urutan angka yang panjang.

Karena itu, sistem penamaan domain dibuat dalam bentuk kata untuk menggantikan urutan angka tersebut.

Bagian-bagian domain mencakup nama domain dan ekstensi yang digunakan.

Contohnya, pada wikipedia.org, nama domainnya adalah wikipedia dan ekstensinya adalah .org.

Pada awalnya, ekstensi domain tidak begitu banyak. Sekarang ekstensi domain sangat beragam, di antaranya .com, .edu, .co.id, .gov, .org, dan sebagainya.

Pemberian ekstensi terhadap suatu domain tidak boleh sembarangan, terutama untuk ekstensi seperti .edu, .gov, dan .go.id yang diperuntukkan bagi lembaga pendidikan atau pemerintah dan memiliki persyaratan khusus.

Subdomain

Subdomain dapat dianalogikan seperti bab dan subbab dalam sebuah buku. Subdomain merupakan bagian dari sebuah domain.

Contohnya, pada alamat id.wikipedia.org, wikipedia.org merupakan domain dan id merupakan subdomain dari domain tersebut.

Top-Level Domain

Top-Level Domain Name (TLD) adalah deretan karakter di belakang nama domain.

Ada dua macam TLD, yaitu Global Top-Level Domain (gTLD) dan Country Code Top-Level Domain (ccTLD).

Contoh gTLD adalah:

.com (dot commercial), umumnya untuk komersial.

.net (dot network), berkaitan dengan jaringan.

.org (dot organization), umumnya untuk organisasi.

.edu (dot education), untuk pendidikan dengan persyaratan tertentu.

.gov (dot government), untuk pemerintahan dengan persyaratan tertentu.

.mil (dot military), untuk keperluan militer dengan persyaratan tertentu.

Contoh ccTLD adalah kode negara, seperti Indonesia dengan .id, Korea dengan .kr, Singapura dengan .sg, Malaysia dengan .my, China dengan .cn, dan Jepang dengan .jp.

Second-Level Domain (SLD)

Second-Level Domain Name (SLD) adalah nama domain yang didaftarkan.

Misalnya, jika nama domain yang didaftarkan adalah domainku.com, maka domainku adalah SLD dan .com adalah TLD.

Third-Level Domain

Third-Level Domain adalah nama sebelum Second-Level Domain dan Top-Level Domain. Misalnya, pemilik domain domainku.com dapat menambahkan nama lain di depannya, seperti mail.domainku.com atau search.domainku.com.

Jenis Domain

Domain dibedakan dalam beberapa tipe sesuai dengan tujuan dan kegunaan masing-masing.

Pengguna dapat memilih dan menggunakan domain yang diinginkan, kecuali beberapa domain yang membutuhkan izin khusus. Penggunaan domain harus dipertanggungjawabkan. Sebaiknya penggunaan ekstensi domain sesuai dengan isi situs, misalnya domain .info digunakan untuk media informasi.

GTLD (Generic Top-Level Domain)

Domain jenis ini pada awalnya banyak dikaitkan dengan penggunaan di Amerika Serikat, tetapi beberapa gTLD kemudian digunakan secara luas di seluruh dunia dan tampak seperti domain standar untuk alamat Internet.

Contoh GTLD:

.com: digunakan untuk kepentingan komersial atau perusahaan.

.net: digunakan untuk kepentingan jaringan infrastruktur.

.org: digunakan untuk kepentingan organisasi.

.info: digunakan untuk situs informasional.

.name: digunakan untuk kepentingan keluarga atau perorangan.

.edu: digunakan untuk pendidikan dengan persyaratan tertentu.

.mil: digunakan untuk militer dengan persyaratan tertentu.

.biz: digunakan untuk bisnis.

.tv: sering digunakan untuk hiburan seperti televisi, radio, dan majalah.

.travel: digunakan untuk bisnis pariwisata.

ccTLD (Country Code Top-Level Domains)

ccTLD adalah domain yang disediakan untuk masing-masing negara, seperti:

Korea menggunakan .kr.

Indonesia menggunakan .id.

Singapura menggunakan .sg.

Malaysia menggunakan .my.

China menggunakan .cn.

Jepang menggunakan .jp.

Subdomain Indonesia

Untuk Indonesia, terdapat beberapa ekstensi domain yang digunakan sesuai kategori dan persyaratannya:

.or.id: digunakan untuk organisasi.

.co.id: digunakan untuk komersial.

.go.id: digunakan untuk pemerintahan dan memerlukan izin atau persyaratan dari pihak pemerintah yang bersangkutan.

.ac.id: digunakan untuk pendidikan seperti universitas atau perguruan tinggi.

.sch.id: digunakan untuk sekolah.

.net.id: digunakan untuk penyedia layanan Internet.

.my.id: dapat digunakan untuk umum sesuai ketentuan pendaftarannya.

.web.id: dapat digunakan untuk umum sesuai ketentuan pendaftarannya.
